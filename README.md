# Leo Chopp Manager

Crie o app Bebidas Leo Chopp conforme especificado: tela inicial com RETIRADAS, CONTAGEM, RELATÓRIO e ADM; catálogo dos 82 itens fornecidos organizado por categorias expansíveis, controles de quantidade +/- e data; relatórios com visualização, edição e reenvio sinalizado; ADM protegido por senha 0000 com exclusão. Integre os lançamentos à planilha Google fornecida, no formato solicitado: código na coluna A, data coluna C, 'SAÍDA' coluna D e 'BAR' coluna E, uma linha por item, preenchendo a próxima linha vazia; exclusões devem remover também da planilha. Use esta planilha: https://docs.google.com/spreadsheets/d/16KMCHvRXLrUpd-0AVR4OEvlgk3jYHZpSAHHyIaThQ18/edit?pli=1&gid=2074531545#gid=2074531545. A tela Contagem deve registrar contagens por item e data de forma coerente, com os mesmos controles.
